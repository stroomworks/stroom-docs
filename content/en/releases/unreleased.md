Changes that have been made to Stroom but are not yet in any release are recorded as change entry files in the {{< external-link "unreleased_changes" "https://github.com/gchq/stroom/tree/master/unreleased_changes" >}} directory of the Stroom repository, one file per change.
They are added to the {{< external-link "change log" "https://github.com/gchq/stroom/blob/master/CHANGELOG.md" >}} when the next release is made.

Each release branch has its own `unreleased_changes` directory, so changes waiting for, say, the next v7.14 release are on the `7.14` branch rather than `master`.

The most recent release notes are for [v7.14]({{< relref "v07.14/_index.md" >}}).
